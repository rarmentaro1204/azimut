# Gestionale Studio Legale – POC

Single-page app (nessun build, nessuna dipendenza): apri `index.html` nel browser. I dati sono salvati in `localStorage` (dati demo precaricati).

Funzioni: dashboard con scadenze imminenti · agenda condivisa + personale · to-do · scadenzario fatture · registro clienti con N. RG e tribunale · rubrica clienti/enti (tel, mail, PEC) · ore dipendenti · assistente in linguaggio naturale per creare eventi/scadenze/to-do.
